# SQL Execution Engine Analysis

## Overview

The execution engine is the runtime that executes the bytecode generated by the query planner. SQLite uses a stack-based virtual machine with a set of carefully designed opcodes optimized for database operations.

## Virtual Machine Architecture

### Register Model

The VM uses a register-based model where:
- Each query execution gets a pool of temporary registers
- Registers hold SQL values (NULL, integers, floats, strings, blobs)
- Results flow through registers between operations

## Execution Flow

### SELECT Execution Pattern

```
OpenRead(table_id, cursor)
Rewind(cursor, end_label)

loop_label:
  Column(cursor, 0, reg0)      // Read columns
  Column(cursor, 1, reg1)
  
  Eq(reg0, const, cond)        // WHERE clause
  IfNot(cond, loop_next)
  
  ResultRow(reg0, 2)           // Output
  
loop_next:
  Next(cursor, loop_label)
  
end_label:
Close(cursor)
Halt(0)
```

### INSERT Execution Pattern

```
NewRow(table_id, cursor)
Insert values into registers
InsertRow(cursor, rowid_reg)
ResultRow(rowid_reg, 1)        // Return new rowid
Halt(0)
```

### UPDATE Execution Pattern

```
OpenWrite(table_id, cursor)
Rewind(cursor, end_label)

loop_label:
  Column(cursor, col_index, reg)
  // Compute new value
  UpdateRow(cursor, rowid_reg)
  
loop_next:
  Next(cursor, loop_label)
  
end_label:
Close(cursor)
Halt(0)
```

### DELETE Execution Pattern

```
OpenWrite(table_id, cursor)
Rewind(cursor, end_label)

loop_label:
  DeleteRow(cursor)
  
loop_next:
  Next(cursor, loop_label)
  
end_label:
Close(cursor)
Halt(0)
```

## Execution Engine Implementation

```rust
pub struct ExecutionEngine {
    pub vm: VirtualMachine,
    pub database: Arc<Database>,
    pub max_registers: usize,
}

impl ExecutionEngine {
    pub fn execute(&mut self, program: Vec<Opcode>) -> Result<QueryResult> {
        self.vm.instructions = program;
        self.vm.program_counter = 0;
        
        while self.vm.program_counter < self.vm.instructions.len() {
            let instr = self.vm.instructions[self.vm.program_counter].clone();
            
            match instr {
                Opcode::OpenRead { table_id, cursor_id } => {
                    self.execute_open_read(table_id, cursor_id)?;
                }
                Opcode::Column { cursor_id, column_index, register } => {
                    self.execute_column(cursor_id, column_index, register)?;
                }
                Opcode::ResultRow { start_register, column_count } => {
                    self.execute_result_row(start_register, column_count)?;
                }
                // ... handle other opcodes
                _ => {}
            }
            
            self.vm.program_counter += 1;
        }
        
        Ok(QueryResult {
            rows: self.vm.result_rows.clone(),
            columns: self.vm.output_columns.clone(),
        })
    }
    
    fn execute_open_read(&mut self, table_id: u32, cursor_id: u32) -> Result<()> {
        let cursor = Cursor {
            cursor_id,
            cursor_type: CursorType::TableIterator { table_id },
            position: CursorPosition::Initial,
            value: None,
        };
        self.vm.cursors.insert(cursor_id, cursor);
        Ok(())
    }
    
    fn execute_column(&mut self, cursor_id: u32, column_index: u32, register: u32) -> Result<()> {
        let cursor = self.vm.cursors.get_mut(&cursor_id)
            .ok_or(Error::ExecutionError("Invalid cursor".into()))?;
        
        let value = match &cursor.cursor_type {
            CursorType::TableIterator { table_id } => {
                let table = self.database.get_table(*table_id)?;
                table.get_column_at_position(column_index)?
            }
            _ => return Err(Error::ExecutionError("Invalid cursor type".into())),
        };
        
        if register as usize >= self.vm.registers.len() {
            return Err(Error::ExecutionError("Register out of bounds".into()));
        }
        
        self.vm.registers[register as usize] = value;
        Ok(())
    }
    
    fn execute_result_row(&mut self, start_register: u32, column_count: u32) -> Result<()> {
        let mut row = Vec::new();
        for i in 0..column_count {
            let reg = (start_register + i) as usize;
            if reg >= self.vm.registers.len() {
                return Err(Error::ExecutionError("Register out of bounds".into()));
            }
            row.push(self.vm.registers[reg].clone());
        }
        self.vm.result_rows.push(row);
        Ok(())
    }
}
```

## Query Result

```rust

    pub columns: Vec<(String, SqlType)>,
```

## Performance Optimizations

### 1. Register Allocation
- Pre-allocate registers based on query complexity
- Reuse registers for intermediate results
- Minimize register copying

### 2. Instruction Caching
- Cache compiled programs
- Avoid re-planning identical queries
- Use statement templates for parameterized queries

### 3. Lazy Evaluation
- Don't compute column values until needed
- Push computation into WHERE clauses
- Avoid unnecessary function calls

### 4. Batch Operations
- Process multiple rows at once when possible
- Use vectorized operations for aggregation
- Group comparisons

### 5. Memory Management
- Use memory pools for temporary allocations
- Pre-allocate result buffers
- Streaming results when possible
